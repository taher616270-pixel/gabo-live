# GABO LIVE — Rebuild

A web-first rebuild of GABO LIVE.

The first deliverable is the responsive Arabic Flutter Web experience. Android and iOS will follow from the same Flutter project. A shared Laravel API will serve all clients.

## Stack

- Flutter Web / Flutter mobile
- Laravel API
- MySQL
- Redis
- Agora for voice rooms
- Docker for backend deployment

See [SETUP.md](SETUP.md) for local setup and current implementation status.

> The existing production project is preserved on `main`. Rebuild work is isolated on `flutter-laravel-rebuild`.
